# 2026-11-02 检查与后续优先级

本次检查基于 bbdbd46 后的源码工作区，覆盖更新链路、DNS 转发边界、配置库事务、现有测试及验收记录。不是完整安全审计，也未更换已安装应用或操作实际 VPN 会话。

## 本次修复

- 检查更新原先使用 `URLSession.shared.data` 一次性读取整个响应，缺少应用层大小上限。改为复用有界下载：最多 2,000,000 字节、总时限 20 秒、独立临时会话，仅允许 `api.github.com` 的 HTTPS 请求及重定向。404 继续提示尚无正式 Release，其他 HTTP 状态保留为可辨别错误。
- Release 页面和安装包 URL 原先只检查协议、主机和路径。现在同时拒绝嵌入用户名/密码、非 443 端口、查询参数和片段，使页面打开与下载入口采用一致的来源约束。安装包仍须通过既有 Team ID、签名及 Gatekeeper 核验。
- 每次检查更新先清空先前的安装包和页面入口，顺序重试失败时不再保留上次检查的下载入口。

## 后续优先级

1. **当前提交的安装级回归**：执行已有的 macOS 15/26、Intel/Apple Silicon 安装矩阵，记录三种模式、TCP/UDP、冷暖 DNS、HTTPS median/P95、吞吐及原生 IPv6 路由的结果。不能把旧版安装结果或规划阶段的速度当作本次完整验收。见 [受管连接验收](MANAGED_CONNECTION_ACCEPTANCE.md)。本次未查询远端 Actions 状态。
2. **物理网络可靠性与防泄漏验收**：在测试 Mac 上覆盖 Wi-Fi 切换、休眠唤醒、IPv6 默认路由变化、助手/引擎崩溃，采集国内外 DNS 与出口数据包，并验证退出后的恢复。PF 继续保持实验性默认关闭；回环测试不能证明实际物理出口零泄漏。见 [QA](QA.md)。
3. **最低系统版本**：声明支持 macOS 13，但目前主 CI 覆盖 15/26。最低部署版本审计不等同于 13/14 的实际安装、授权、连接与卸载测试；发布前应补充旧系统的验收记录。
4. **更新交互完善（可选）**：检查更新期间合并重复请求、支持取消，并为超时/限流提供明确重试入口。现有请求仍可并发完成，本次仅处理顺序检查的旧结果清理。
5. **按实际需求扩充认证**：已连接会话内 CRV1 重认证和 SAML/浏览器认证仍在明确的不支持范围。应先收集服务器需求和测试环境，再决定实现顺序；当前优先保证不支持时明确失败。
