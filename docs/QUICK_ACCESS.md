# 快速打开（0.3.4 / Build 7）

应用内按 ⇧⌘P，或在菜单栏选择“快速打开…”，可以唤起 560 × 460 的原生毛玻璃面板。搜索名称、分组和源文件名；支持大小写、重音和全角折叠，多个词需全部匹配。结果优先精确名称、名称前缀，再按收藏和名称排序。不会读取配置正文、私钥、凭据或备注。

方向键循环选择，回车连接/查看，Esc 取消确认或关闭。点击其他窗口后面板关闭；搜索内容只在内存中，关闭后清空。面板复用同一个 NSPanel，按鼠标所在屏幕的可用区域居中偏上放置。中文输入法有待提交的组合文本时不拦截导航/回车/Esc。

连接与主窗口共享 AppModel。正在认证、停止、维护、修改后台服务或尚不能安全开始会话时不执行连接。当前活动配置只打开主窗口；其他配置先显示“断开并连接”确认，不能靠连续按回车确认。确认时及启动前分别重新核验配置和活动会话；状态已改变时不切换。实际连接、清理与切换复用现有安全流程，凭据/私钥/OTP 在主窗口输入。安装未就绪时显示原有连接前检查，不注册 root 服务或跳过批准。

## 全局快捷键

在“连接偏好”启用：⌃⌥⌘V、⌃⌥⌘J 或 ⌃⌥⌘空格。默认关闭，保存选择；应用保持运行时可用。使用 Carbon RegisterEventHotKey 注册指定组合，不安装 event tap，不监视普通键盘输入。系统拒绝注册时显示错误和重试入口，不抢占其他应用的组合。更换、关闭或正常退出释放注册，已排队的旧回调在变更后丢弃。

## 自动化边界

核心测试覆盖元数据搜索、Unicode、排序、超长输入、选择循环及会话安全决策。原生发布 UI 的自检创建真实 NSPanel，以 NSEvent 验证导航/关闭及过期确认；实际注册三个 Carbon 组合并检查冲突拒绝/释放，以限定 hotkey 事件验证回调。所有测试配置只在内存，不启动 VPN。工作流另截图快速面板。

这些证据不等于跨应用物理按键、不同输入法/键盘布局、多显示器和全屏空间的真机验收；它们继续列为人工验收项。是否通过以本次 PR 的 Actions 为准，不据此公开发布 Beta。
