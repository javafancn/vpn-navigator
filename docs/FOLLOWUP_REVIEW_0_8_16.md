# 0.8.16 / Build 36：缓存错误处理补充检查

检查了连接失败后的 DNS/路由恢复与退出保护、模式切换、安装/卸载及辅助操作的错误传播。未改动本机已安装应用、实际 DNS 或路由。

## 已确认并修复

OpenVPN 的 `macos-dns-updown.sh` 在原生助手成功应用 DNS 后，最后执行 `dscacheutil -flushcache`，脚本会直接返回该缓存命令的退出码。缓存刷新失败仍可能让 OpenVPN 报 DNS hook 失败。0.8.15 仅修复原生助手侧，没有覆盖此脚本路径；Original 模式也使用该脚本。

0.8.16 让此处缓存刷新尽力执行。原生 DNS 应用失败仍立即以失败退出，未经校验的输入仍在调用助手前被拒绝；dns-down 仍由助手日志恢复，没有加入强制系统清理或退出绕过。

新增测试实际执行随包脚本，仅重定向临时运行目录、原生助手和缓存命令边界。四项用例覆盖缓存返回 0/1/127、DNS 应用失败、dns-down 无修改和非法输入；没有修改系统 DNS。相同测试对修复前脚本的两种缓存失败场景均能复现失败。
