# 原生玻璃与交互打磨

## 光学层次

窗口、侧栏、内容底板、卡片和输入框使用中性的透白层。移除覆盖窗口的蓝紫渐变、侧栏蓝灰染色、主卡片青色径向光，以及用于校色的旧材质预设。色彩从窗口后方的真实桌面进入；蓝色只用于品牌、主操作、选中态和电源控件。

窗口只保留一个完整不透明度的 AppKit `NSVisualEffectView`，其材质为 `.sidebar`、混合模式为 `.behindWindow`。不通过降低模糊视图透明度来暴露未经模糊的桌面，也不在每张卡片上重复创建模糊视图。卡片仅加16%透白层、0.75pt细边缘和弱中性阴影。

## 交互

- 主按钮和次按钮提供120ms悬停/按压反馈；按压轻微缩放，不改变布局尺寸。
- 导航、配置列表、路由选择、图标和菜单操作提供轻量反馈，禁用状态不呈现可点击的悬停效果。
- 侧栏与检查器/诊断分段选择标记使用匹配几何过渡，阻尼弹簧300ms。
- 页面使用160ms透明度过渡，窗口和卡片布局不参与切页动画。
- 搜索、配置名称和备注使用真正的输入焦点驱动描边；不在容器上抢占键盘焦点。
- 遵循系统“减弱动态效果”和“降低透明度”设置。无持续呼吸动画、装饰计时器或常驻动画循环。

## 视觉验证

五页仍在同一个1100×700窗口中抓取。额外使用同一二进制、相同界面、两种外部桌面校准图进行验证：冷色和暖色都由CI脚本设置到macOS桌面，不作为应用资源发布。检查截图中玻璃背板随桌面改变，而按钮和选中态保持相同蓝色。

桌面校准脚本只位于 `scripts/capture-glass-calibration.swift`，应用不会修改用户壁纸。构建步骤仍包含双架构检查、签名校验和ZIP完整性验证。
