# 自定义分流、路由解释与一键排障

0.4.0 / Build 13 增加三个入口，位于路由工作区；配置详情菜单也可打开自定义规则。

## 自定义分流规则

每个配置可独立保存最多 128 条 IPv4 规则，动作是“直连”或“走 VPN”。可输入单个地址或 /8–/32 CIDR；保存时归一化网段地址。可停用、启用或删除规则；启用规则不能互相重叠，停用项仍占数量上限。IPv6、域名和按应用分流不在本次实现范围内。

规则用于全局 VPN 和中国 IPv4 直连模式，原始配置模式不应用这些规则。规则优先于地区库：直连项加入物理出口路由；走 VPN 项从地区直连范围中扣除。扣除后的同一份前缀同时用于路由和实验性 PF 物理出口放行范围，避免路由已回到 VPN、防火墙仍保留宽泛直连许可。组合结果上限为 30000 条。

回环、链路本地、共享地址、文档地址、组播和保留地址不能用于自定义规则。RFC1918 私网允许使用，但连接时不能覆盖当前物理接口的局域网网段或 VPN 服务器端点；冲突时拒绝连接，提示调整规则。端点和当前局域网保留原有保护边界。

规则在下次连接时生效，当前活动配置需断开后才能编辑。编辑使用配置 ID 和原始规则快照防止过期窗口覆盖新内容。助手在开始连接时验证并保存策略快照，自动重连、在线全局/规则模式切换和地区库更新均复用该策略；会话报告返回实际规则数量与指纹，界面不会把尚未应用的保存值当成当前策略。

配置索引备份与恢复包含规则，旧索引缺少该字段时默认为空。便携 OpenVPN 导出不携带应用策略；静态路由预览包含自定义例外，但不代表当前系统路由已安装。

## 路由解释

输入 IPv4 后可查看命中的自定义规则、地区直连前缀或 VPN 默认路径。

- **策略预览**使用选中配置及缓存地区库，不读取 VPN 服务器端点和当前局域网，也不验证系统状态。
- **当前连接核验**由助手使用本次连接的实际策略计算预期路径，并只读查询系统 `route get` 的接口与网关，显示是否符合预期。原始配置模式仅展示系统观测，不声称由应用决定路径。

核验请求绑定配置 ID、连接尝试 ID、模式和路由版本；助手处理前和客户端收到结果后均检查会话，过期结果不展示。查询不会增删路由、修改 DNS 或发起目标网络连接。其他软件安装的更具体路由可能造成预期与观测不符；单次路由表采样不证明数据已送达，也不证明不存在泄漏。

## 一键排障

打开窗口不会自动探测；点击开始后按序检查助手与会话、配置语法与支持范围、地区库和规则指纹、本机路由与 IPv6 状态、用户所选域名的系统 DNS 查询、用户所选 IPv4/端口的 TCP 连接、本次会话实际路由以及近期结构化错误类别。

每项独立展示结果与建议。TCP/DNS 失败只表示所选目标或解析失败，不直接判定 VPN 断开；配置检查不替代证书与服务器握手验证。未连接时跳过 VPN 实际路径核验，普通网络连通不能作为 VPN 生效证明。IPv6 状态与助手保护报告不构成无泄漏证明。

检查支持取消，整体限时 30 秒，超时保留已完成结果；取消或重启后旧任务不能回写结果。期间会话变化时标记采样过期，建议重新检查。此功能只采样并给出操作建议，不自动重启连接、修改配置、恢复网络或调整系统 DNS。结果保留在当前窗口内，不上传原始配置、地址或日志，现有脱敏诊断导出策略保持不变。

## 验证范围

新增核心测试覆盖规则归一化与边界、重叠和数量限制、直连区间扣除、路由与 PF 一致性、模式往返、导出与索引兼容、路由核验身份及排障结果解释。助手注入式路由测试覆盖策略切换顺序和撤销；本机安装集成测试在真实 TLS 会话中检查只读路由接口及过期/非法请求拒绝。原生应用自检覆盖保存与编辑锁、规则回执、真实回环 TCP/系统 DNS、取消、重启、超时和过期会话，另生成三个工具窗口的原生截图供检查。

实际服务器上的公网分流、PF/IPv6/DNS 流量、网络切换、休眠恢复和长时间运行仍属于发布前的物理环境验收。本次不发布 Beta 或 Release。
