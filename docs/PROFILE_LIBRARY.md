# 配置库筛选、排序与分组复用

0.3.9 / Build 12 将配置列表顶部的静态箭头接入实际筛选菜单。

- 支持全部、收藏和现有分组，显示筛选结果数/总数及每组数量。
- 搜索与筛选叠加，复用快速打开的多词匹配及大小写、重音、全角折叠；仅检索名称、分组、源文件名，不检索备注、路径、证书或凭据。查询最多 256 字。
- 提供收藏优先（搜索时保留精确/前缀相关性）、名称自然排序和最近导入排序；重名/同时间有稳定 UUID 次序。只持久化排序枚举，不保存搜索词或分组筛选。
- 筛选不会改变选中配置、实际活动会话或凭据。隐藏当前选择时显示明确提示及“显示当前选择”入口；同一页面内暂时隐藏的编辑器保留草稿，并禁用隐藏控件的输入与操作。
- 分组菜单从实际元数据更新，自定义分组保存后可在其它配置中复用。自定义输入取消不改变草稿，空白或超过 48 字的名称不能确认。最后一个分组成员移出/删除后，旧组筛选退回全部；空收藏或无匹配的搜索保留显式空结果。
- 列表使用助手已回报的实际连接 ID 标识活动配置，查看和筛选均不发出 VPN 请求。

## 配置操作

保存、收藏、删除及导出入口绑定发起操作的配置 UUID。保存从存储重新读取最新元数据，保留最新的默认路由策略；收藏只改收藏标记，不顺带保存未提交的其它草稿。写入期间互斥其它配置操作并阻止正常退出；恢复、导入、维护和模式切换沿用同一忙碌限制。

删除在断开、助手状态可核验、没有网络恢复或其它操作待完成时启用。确认后仍复查状态并按原 UUID 删除，不使用后来改变的选择。原有单项 Keychain 清理继续按该 UUID 执行；不引入凭据批量操作。配置索引更新继续自动生成上一轮提供的私有恢复备份。

## 验证

新增 10 项核心测试覆盖筛选组合、折叠搜索/敏感字段排除、分组计数、组消失、自然排序与稳定排序、相关性、分组复用、清除筛选和未知偏好回退。

原生 AppModel 自检使用临时配置与隔离偏好，检查隐藏选择、排序恢复、按原 UUID 写入、保存时路由策略保留、独立收藏、活动会话删除拒绝、写入时 Quit 阻止及索引备份一致性。自检不建立 VPN、不访问真实凭据。工作流截图普通配置库、分组筛选和空结果；完整结果以本轮 PR Actions 为准。
