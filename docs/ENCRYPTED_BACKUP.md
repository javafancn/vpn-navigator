# 加密备份与迁移

0.5.1（Build 15）增加配置库的完整加密备份。入口：设置与维护 → 加密备份与迁移。

## 创建备份

选择“创建备份”，输入并确认至少 12 个字符的独立密码，确认文件可能包含私钥后保存 `.vpnnavbackup`。最多 1000 个配置、每配置 1000 个历史版本、全库最多 10000 个历史版本；加密文件最多 16 MB。超过限制会拒绝，不会悄悄截断历史。

备份包含配置名称、原始文件、已经内联证书与私钥的运行副本、分组、收藏、备注、路由模式、自定义 IPv4/IPv6 规则和历史版本。原始配置中的外部材料引用保留为原文；恢复和运行使用随备份保存的自包含副本，不读取原电脑上的路径。

不读取或备份钥匙串、连接输入框密码、系统授权、登录服务、通知/自动连接偏好、规则缓存、诊断记录或 DNS/路由/PF 恢复日志。配置文件本身可能含私钥或其它敏感材料。密码仅用于本次加解密，无法找回；未创建云账户，也不上传备份。

## 解密、预览和恢复

选择备份并输入密码后，在本机解密并校验内容；确认前只在内存持有预览，不将明文解压到临时目录。预览显示将恢复的配置、路由模式与历史版本数量。

恢复前必须断开 VPN、确认助手状态并完成网络恢复。确认恢复时重新核对会话和配置列表。所有配置分配新 UUID，同名项也新增，不覆盖已有配置，不继承旧 ID 对应的钥匙串凭据，不自动连接或开启系统服务。再次恢复会新增另一份副本。

恢复过程中先写入当前用户专属的暂存目录，再移动已验证的文件，最后一次性发布配置索引。元数据索引发布是提交点；此后显示成功，即使取消请求恰好同时到达。取消在提交前生效。

写前恢复记录只包含本次新建的 ID 和暂存目录 ID。中断后，配置库读取会清理未提交的新文件与暂存目录；已在索引中的配置保留。无法核验的记录、损坏索引、链接或异常文件会保留现场并停止恢复，不猜测删除。原有索引恢复功能可处理损坏的配置列表。

## 文件和密码保护

使用系统随机盐、PBKDF2-HMAC-SHA256（600000 轮、256 位密钥）与 CryptoKit AES-256-GCM。文件头版本、固定 KDF 参数和盐也纳入认证。文件中不公开配置名称或条目列表。没有压缩或归档路径解包功能。

版本和 KDF 参数固定、读取有界；不接受文件指定的任意计算量。错误密码与密文损坏统一报告解密失败，未知格式先拒绝。密码最多 1024 UTF-8 字节。源文件、恢复文件、历史和暂存内容保存在当前用户私有目录；导出的密文文件使用 0600 权限和原子替换。

密码输入在操作开始、取消/关闭后清理，密钥字节尽力清除；Swift 字符串和系统内存复制不提供可验证的全内存清零保证。备份强度仍依赖用户密码与设备安全。

## 验证范围

自动化覆盖独立 Python PBKDF2/AES-GCM 兼容向量、随机化、错误密码、头/盐/nonce/密文/tag 篡改、大小/格式约束、UTF-8 密码、源文件及历史迁移、新 ID/重复恢复、过期确认、取消、提交前失败、中断清理与提交后保留，以及历史目录链接拒绝。

原生自检覆盖密码确认、输入清理、快速打开/智能连接排除、真实密文保存与预览、活动 VPN 拒绝恢复、取消和退出屏障；流水线生成设置界面截图。编译和用例结果以本次 PR 对应的 macOS CI 为准。

Finder/保存对话框、外置文件系统、文件提供方、真正断电与用户操作仍需真机验收。本功能不替代现有的网络恢复、发布签名或公网防泄漏验收。

参考：[Apple CryptoKit AES.GCM](https://developer.apple.com/documentation/cryptokit/aes/gcm)、[OWASP 密码派生参数](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
