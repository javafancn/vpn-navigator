# 设计优化：更轻的导航与更清楚的信息层级

本轮在原有原生毛玻璃基础上调整信息组织，不改变连接、路由、凭据或规则更新逻辑。

- 侧栏收至228pt，导航统一16pt/44pt；五个入口始终固定，移除其他页面中含义不明确的“个人”入口。
- 导入入口移至侧栏底部，并提供⌘O；底部显示真实连接状态与配置数量。
- 五页标题使用28pt，统一上边距、24pt内容边距和副标题；移除重复品牌图标与悬浮加号。
- 总览连接按钮收敛多层霓虹光圈，保留蓝色主操作与细玻璃外环；区分配置名称与源文件。
- 路由页显示当前配置与策略生效说明，调整选项和规则卡比例。
- 诊断页将分段标签与重新检查置于独立工具栏；显示每项诊断含义，增加路径节点间距。
- 设置按“系统与网络”“应用”分为两组，同组项目使用细分隔线，减少重复卡片边框。

默认窗口保持1100×700、11:7比例。玻璃仍由单个AppKit behindWindow材质与中性透白层组成，应用不绘制壁纸或环境渐变。遵循降低透明度和减弱动态效果设置。

验证采用GitHub macOS构建与五页真实运行截图；冷暖校准图仅设置外部桌面，不打包进应用。截图夹具仅生成配置列表，不伪造VPN连接、速度或网络结果。测试包不包含OpenVPN引擎，采用ad-hoc签名，未经Apple公证。
