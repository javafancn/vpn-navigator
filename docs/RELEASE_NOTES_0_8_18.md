# 0.8.18 / Build 38

状态栏菜单展开期间保持同一组原生菜单项与子菜单，避免状态轮询和流量刷新打断选择。关闭后再次打开时读取最新状态；操作执行前重新检查连接、配置和忙碌状态，过时的“断开”操作不会变为重连。后台采样继续运行，菜单展开期间保留展示快照。

DNS 缓存新增带 SOA 的 NODATA 回复，覆盖 AAAA、HTTPS 等查询。缓存回复中的 SOA TTL 与本地负缓存寿命都从 `min(SOA TTL, SOA.MINIMUM)` 开始递减；更短的原始 TTL 不会被延长。零 TTL、无 SOA 的空回复、错误和纯转介继续不缓存。

UDP 配置未显式指定时，发送与接收缓冲区分别使用 512 KiB；已指定的参数保留。导入时校验缓冲区数值为 0 至 4 MiB。TCP 不重复添加显式的 `TCP_NODELAY`，候选端点等待时间继续保留用户的超时设置。

中国直连 DNS 增加部分 Apple 网站、软件更新与内容分发域名，按完整 DNS 标签及子域匹配；不将整个 `apple.com` 纳入直连，`tv.apple.com` 仍走 VPN DNS。全局 VPN 模式保持 VPN DNS 策略。

本机验证覆盖应用与助手编译、原生菜单实际事件跟踪期间持续更新、菜单命令与过时操作、窗口关闭及重开、DNS 负缓存 TTL 边界，以及真实回环 UDP/TCP 中继的缓存、过期、故障切换与模式隔离。本地化和差异格式检查通过。应用编译使用本机兼容的 macOS 26.5 SDK；完整 XCTest 测试仍受本机缺少 XCTest 模块限制，跨架构、签名安装包及真实 VPN 网络验收以相应 CI 和实机记录为准。
