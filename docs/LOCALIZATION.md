# 界面语言与本地化

0.8.0 / Build 20。入口：设置与维护 → 界面语言。支持跟随系统、简体中文及 English；系统首选语言无中文或英文时回退 English。

选择立即保存，仅下次启动生效。应用不会主动退出、断开或重连；当前会话、路由、规则版本、配置及凭据标识均不改变。显式语言选择同步本应用偏好域的 AppleLanguages；跟随系统移除该应用覆盖，不修改系统或其它应用语言。

覆盖主窗口五页、快速面板、原生工作区／帮助菜单、连接认证、诊断、路由工具、配置导入／健康／更新、加密备份、历史、维护及通知。应用内错误和日期使用启动时的语言快照。语言名称采用自身语言。配置名称、分组、文件名、服务器地址、用户输入与原始技术输出不翻译；服务端认证挑战保留原文，应用生成的私钥密码提示本地化。各类 ID、枚举原始值、JSON 键、命令及协议保持兼容。

`Resources/Localization/catalog.json` 是双语文案源。`scripts/check-localization.py --generate` 生成内嵌 Swift 数据；正常检查验证生成同步、唯一键、非空译文、占位符一致和生产代码覆盖。元数据、语言原名、原生标题识别及稳定原始枚举值列入显式豁免。内嵌 catalog 不依赖部署路径或 SwiftPM 资源 bundle，助手和安装后的应用均无资源查找崩溃风险。系统权限说明通过 en／zh-Hans 的 InfoPlist.strings 随应用打包。

模板按单次扫描替换 `{0}` 等占位符，支持译文调整语序；不会对参数内容二次替换、翻译或解释格式指令。语言状态在进程内不可变。测试通过隔离偏好域验证选择保存、系统回退、数据／协议兼容、参数保真及当前会话保持。

CI 保留中文回归，并额外运行英文应用快照、双语键盘回归和英文五工作区／语言面板／帮助／健康／备份／出口截图。`--vpnnav-language=en` 或 `zh-Hans` 仅在 GITHUB_ACTIONS=true 时用于确定性验收，不写用户偏好。完整 VoiceOver、系统权限与文件面板的实际语言切换、中文输入法及 macOS 13 仍保留真机验收；不将 CI 中未暴露的辅助功能树计为通过。
