# 键盘与辅助功能

0.7.1 / Build 19。日常主窗口操作、读屏语义及系统显示偏好适配；不是无障碍标准认证或全量双语本地化。

## 入口和操作

原生菜单「工作区」提供 ⌘1–5：连接总览、配置文件、路由与规则、网络诊断、设置与维护。⌘F 从任意工作区打开配置页并聚焦搜索；连续按 ⌘F 仍重新聚焦。快捷键绑定当前主窗口的 focused scene，不使用全局键盘监听。独立设置窗口没有这些主窗口动作。

「帮助 → 键盘与辅助功能…」列出快捷键、键盘导航设置与系统偏好。保留现有 ⌘O 导入、⇧⌘P 快速打开，以及用户选择开启的全局快速打开快捷键。

配置搜索保留系统文本编辑和输入法：没有劫持左右／上下箭头、Escape 或标记文本。按 Return 后，选择当前可见配置（否则首个结果），并将焦点交给列表。无结果时保留文本焦点及之前的选择。列表行获得焦点时可用 ↑↓ 在当前筛选／排序结果中移动；到达边界停止、不循环。选择仅更新 UUID 与详情，不发起连接、不切换活动 VPN。焦点随选择滚动；筛选使焦点行消失时回到搜索，不自动选中隐藏项。

在系统设置「键盘」开启键盘导航后，Tab／⇧Tab 遍历原生可聚焦控件，空格执行按钮。保留系统焦点效果，并为共享自定义按钮及配置行提供焦点边框。打开认证、备份、导入、编辑或其它应用 sheet 时，工作区快捷键停用，动作执行时再次检查。原生模态文件／授权面板也阻止后台导航。帮助 sheet 计入智能连接及快速打开的占用检查。

## 读屏与显示

- 工作区、配置详情与诊断的自定义分段项提供选择状态；配置列表和快速面板行读取名称、分组、收藏、连接及选择状态。只包含屏幕上已有元数据。
- 图标按钮补充身份验证、配置操作、收藏及诊断目标的明确名称。主连接按钮分别命名连接／取消／断开／解除保护；状态作为可访问值。安全输入框继续由系统负责，不添加密码朗读或日志。
- 详情元数据按标题和值组合；共享表单控件沿用外部字段名称。流量趋势提供采样数量和最后字节增量文字，不以图形曲线作为唯一信息。
- 列表的当前选择增加勾选形状，读屏可独立获取收藏／连接状态，不仅通过颜色判断。
- 增强对比度时，背景和卡片使用不透明系统背景，表单和分段容器使用系统底色，边框加深加粗；普通模式保留原有原生毛玻璃。原有「降低透明度」「减少动态效果」适配继续生效。

## 验收与边界

Native development package 工作流运行 `--vpnnav-workspace-accessibility-self-test`。测试从真实 SwiftUI 主窗口启动，通过生成的 AppKit 菜单分发 ⌘1／⌘2／⌘F，读取应用自身的辅助功能树，发送 Return／方向键并检查实际第一响应者、列表边界、空结果、辅助选择操作和对话框占用。使用内存配置；不保存配置、不调用 VPN、不请求公网、不申请控制其它应用的辅助功能权限。CI 启用键盘导航仅作用于临时 runner。

同一发布 UI 二进制捕获普通五工作区、帮助窗口及增强对比度配置页。`--vpnnav-ui-high-contrast-snapshot` 仅在 GITHUB_ACTIONS=true 时覆盖该主视图的对比度环境，用于稳定截图；运行中的系统偏好仍由 SwiftUI 环境驱动。

仍需实际 Mac 验收：完整 VoiceOver 连续朗读与焦点顺序、中文输入法候选与 Return 提交、键盘导航开关、通知／认证／文件面板交接、系统显示偏好实时切换、第三方辅助技术及 macOS 13。自动化只验证覆盖的入口，不证明所有弹窗和第三方技术无障碍。全量中英文切换及完整本地化尚未实现。
