# 智能连接与状态通知

实现目标版本：0.5.0（Build 14）。自动连接和系统通知默认关闭，分别主动开启。

入口：设置与维护 → 智能连接与状态通知 → 配置。菜单栏还提供智能连接、暂停／恢复自动连接与设置入口。

## 连接行为

- 配置可固定选择，或使用最近成功连接的配置。成功记录只来自已核验的助手会话；受管模式还必须有路由回执。已删除的固定配置不会自动替换。
- 自动连接没有成功记录时需先手动成功连接一次，或选择固定配置；手动“智能连接”还可选择收藏配置。
- 可分别开启应用启动、系统唤醒、网络恢复／物理网络切换触发。应用启动包含登录启动；登录启动开关仍在连接偏好中。
- 触发后等待 2.5 秒，再读取助手状态和当前网络条件。应用关闭后不运行，关闭窗口但保留应用时继续运行。
- 可限定任意可用物理网络、Wi-Fi、有线或精确 Wi-Fi 名称。默认跳过系统标记为按流量计费的网络。
- 指定 Wi-Fi 必须取得当前名称并精确匹配。读取失败、未授权或名称不匹配时跳过；不会用网关或名称猜测网络可信度。名称区分大小写。
- Wi-Fi 位置授权只在点击授权按钮时请求，不启动位置更新，不获取地理坐标。仅保存用户明确配置的 Wi-Fi 名称，观察到的网络身份不落盘、不进入通知或诊断导出。
- 自动触发不切换现有会话，不自动启用助手，不自动修复安装，不关闭认证／编辑对话框。应用正在处理其它操作时跳过本次触发，等待下一次事件。
- 自动连接只使用用户选择保存的钥匙串凭据，读取时禁止钥匙串交互。不读取输入框中的临时密码，不自动填写动态验证码。缺少凭据时停止并提示手动处理。
- 手动断开会持久暂停自动连接。恢复按钮解除暂停后等待下一次触发；手动连接不会偷偷恢复自动连接。
- 连接失败会暂停自动连接，检查后需主动恢复。活动会话内的断线重连继续使用原有 Original／受管模式重连策略，不叠加无限重试；受管模式安全重连仍要求断线保护。
- 休眠、暂停、设置变动或手动连接会撤销排队任务。异步读取配置后，在助手调用前再次检查任务、目标与网络条件。

## 通知行为

使用 macOS 本地 UserNotifications，不使用 APNs 或第三方通知服务。只有开启系统通知时请求系统授权。

默认只提示异常和认证请求，也可包含已连接、正在重连及正常断开。认证失败、证书／TLS 错误、意外中断、状态不可核验与网络恢复未完成分别提示。声音默认关闭。

通知依据助手结构化状态，不把原始引擎消息当作通知内容；同一会话、认证挑战或恢复事件去重；助手状态反复失联的提醒至少间隔 60 秒。启动时接管已有连接不发送“刚刚连接成功”。通知正文不含配置名称、SSID、服务器地址、域名、认证提示内容或凭据；点击打开主窗口，不执行连接动作。

测试按钮只提交本地通知。实际横幅和声音由系统授权、通知设置及专注模式决定。未授权时显示状态和设置入口，不承诺已显示横幅。

## 验证与待验收

- Core 单元测试覆盖默认关闭、触发／暂停、网络约束、SSID 不可读、计费网络、会话占用、助手未知／恢复记录、目标优先级、损坏设置、通知去重与旧报告兼容。
- 原生自检使用临时配置和隔离 UserDefaults，覆盖成功记录、排队取消、手动暂停持久化、交互凭据／许可栅栏、现有会话、失败暂停和通知关闭。自检不请求系统权限、不连接真实 VPN。
- Native UI 流水线增加设置页截图。
- 真机验收仍需：登录启动、睡眠／唤醒、Wi-Fi／有线切换、按流量计费网络、位置权限允许／拒绝、通知允许／拒绝与专注模式、钥匙串锁定、MFA／证书过期和服务失联。CI 不能代替这些物理网络与系统权限验收。
- 本文描述实现与检查项，测试结果以对应提交的 CI 为准；未运行项不能视为通过。不改变 Beta／Release 的真机验收门槛。

API 参考：[NWPathMonitor](https://developer.apple.com/documentation/network/nwpathmonitor)、[UNUserNotificationCenter](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter)、[CWInterface.ssid](https://developer.apple.com/documentation/corewlan/cwinterface/ssid())。
