# VPN Navigator — 五页面视觉差异与验收方案（2026-10-16）

## 对比基线
- **代码**：`feat/reference-glass-ui`（不是未合并代码所缺失的 `main`）。
- **运行截图**：用户提供的五张主界面截图；**设计目标**：用户提供的第六张拼版设计图。
- 原设计图中山景是视觉示例背景。运行截图使用用户真实桌面壁纸，**不能把山景烘焙进窗口**。应在同一桌面、相同窗口点尺寸、相同显示缩放、浅色模式、关闭“降低透明度”下比较。
- 设计示例中已连接时长、美国出口与吞吐统计不代表真实会话数据；网络数值必须来自已有状态模型。
- 此 PR 是**第一轮视觉校准**；macOS 实机截图/不同壁纸材质验证仍是必要验收步骤。

## 共性问题与修复
1. **窗口/侧栏比例**：运行截图的侧栏、顶部品牌区域相对于内容区偏宽偏疏。目标缩小侧栏宽度 254→238pt，品牌区顶部与底部留白缩小，导航行 43→41pt。保留原导航能力。
2. **顶部层级**：页面标题相对设计图较大，标题与卡片之间存在明显空白。统一标题 27→25pt，页面顶部空白 29–34→23pt；总览标题下方额外间距 33→17pt。
3. **通透性**：原来的玻璃效果过多依赖系统壁纸和 macOS 材质组合，卡片近似灰色。保留真实 `NSVisualEffectView` 模糊和无背景壁纸方案，调整轻蓝白 mist、窗口和卡片独立透明层及局部斜向高光；继续尊重系统“降低透明度”设置。
4. **系统颜色**：蓝色作为主要操作色；次要面板以柔和白蓝和细高光描边，避免强不透明白块。统一 `GlassLayout` 令牌用于后续更细的页面校准。
5. **行为边界**：不动 VPN helper、密钥、路由安全、状态与网络协议；纯视觉重排不得伪造成功状态、流量数据或 IPv6 安全保证。

## 1. 连接总览
**差距**：运行图顶部标题卡片垂距过大，电源区高度占比偏高；底部接收/发送/保护卡片比拼版松散。背景透过时壁纸细节对文字有干扰。

**第一轮改动**：缩小标题到主体间距，主按钮卡片高度 316→304pt；统计卡内容高度 130→104pt；保护卡 156→130pt。保留电源光晕、当前连接、配置菜单、身份验证折叠区、真实流量图及未连接状态。

**进一步验收**：总览在推荐窗口大小下无需纵向滚动；左主卡与右快捷连接、当前连接模块齐平；底部 3 卡高度一致；连接状态/计时器和流量不能展示假值；背景信息足够模糊，所有文本保持可读。

## 2. 配置文件
**差距**：运行图配置列表区比设计相对宽，右检查器信息密度较低；筛选列表与详情的视觉连续性较弱。

**第一轮改动**：配置列表宽度 245→215pt；同步收紧页面顶部距离，保留搜索/导入/收藏、四个检查器选项、可编辑名称类别备注和安全编辑/版本操作。

**进一步验收**：选中项清晰但非实心蓝块；列表和详情面板等高；主表单的文字列对齐且不截断；窄窗口时保留详情滚动和操作按钮访问能力；不能改写原始配置或丢失历史。

## 3. 路由与规则
**差距**：运行图左侧策略行和右侧网段信息块比较松，设计目标相对紧凑；空白区域多，IPv6 卡片与主卡间隔需统一。

**第一轮改动**：主分栏内边距 17→15pt，模式选项最小高度 66→59pt，页头距离同步收紧。

**进一步验收**：Original / Full VPN / 中国 IPv4 直连三个模式始终可见；禁用、运行中不能编辑的状态正确；右栏网段数、时间及来源真实，历史版本的选择和恢复确认仍可使用；IPv6 继续明确为预览。

## 4. 网络诊断
**差距**：运行图左侧检测表偏大、顶部标签与画面内容密度不均；设计图的检测结果卡和路线节点层级更清晰。

**第一轮改动**：头部诊断标签总宽 360→345pt、标签行高 29→30pt，页面横向间距统一为设计令牌。

**进一步验收**：连接测试、DNS、路由追踪、延迟四选项状态区分明显；左结果行与右路径卡片对齐，警告用橙色、成功仅用于实际检测结果；禁止模拟延迟和地理位置；未知网络安全结果仍显示未知。

## 5. 设置与维护
**差距**：四张设置卡相比设计图偏高，内容占据偏多垂直空间；右侧操作状态距离边缘不完全一致。

**第一轮改动**：四张设置卡最小高度 84→73pt，页面标题/卡片区顶部空白统一减少。

**进一步验收**：特权助手、应用更新、安全恢复、关于四卡等高对齐；不同窗口尺寸下菜单、按钮和状态不溢出；版本号来自 bundle，权限和更新状态来自真实服务；警告不能被设计上的绿色徽标覆盖。
