# 配置迁移与批量导入（0.3.5 / Build 8）

## 可迁移导出

配置详情中的“导出配置…”和菜单“导出可迁移配置…”使用本机已内联证书材料的运行副本。它保留配置原有的路由和认证要求，应用选定的 Original / 全局 / 国内直连策略不会另外写入；国内直连配置即使尚无地区规则缓存也能导出。原目录或邻接证书文件删除后，可将导出文件复制到另一目录重新导入。

三点菜单另提供“导出路由预览…”，明确生成静态策略预览，不表示当前系统路由。两个入口都在保存对话框提示：文件可能包含证书和私钥，需妥善保存。导出不会读取 Keychain、当前密码/OTP 或外部账号文件；它是普通 `.ovpn` 文件，没有文件级加密。

导出先验证副本自包含及兼容性。遗留配置缺少运行副本且仍引用外部证书时拒绝导出，请重新导入完整材料或编辑修复。保存时同目录创建 0600 临时文件、同步后原子替换，拒绝链接、目录及特殊文件目标；失败前保留旧目标，替换硬链接路径不会改写其他别名。所选文件系统需支持私有权限。不会改变正在运行的 VPN。

## 批量导入

文件选择器一次可选 1–100 个 `.ovpn`，按选择顺序处理。结果窗口显示每个文件的成功、失败类别或取消状态，单个失败继续处理后续文件。只显示文件名和预定义原因，不把完整路径、配置正文或系统错误写入报告/日志；结果仅驻留内存，关闭窗口后清空。

取消会等待当前文件完成，保留已成功导入的配置，剩余项不再读取。已有配置不按名称覆盖，新文件使用独立 UUID；当前活动会话保持原有身份，导入完成后选择第一个成功项。安装维护和退出在文件操作结束前受保护，批量文件读写在 ProfileStore actor 上执行，不阻塞界面。首次检查中的单文件导入继续显示简短反馈。

配置与证书读取有大小限制，非普通文件不会阻塞等待。保存源文件、运行副本、索引和历史版本使用私有原子写入；一次导入的索引发布失败时移除该次新建副本。逐文件提交，不承诺整批事务或断电回滚。导入沿用现有文件/材料规则，连接时继续执行完整配置兼容性校验。

## 验证边界

核心测试覆盖跨目录可迁移往返、原材料删除、策略/预览区分、文件名、0600、硬链接、符号链接/目录、大小/FIFO、混合批次、取消、批量上限和索引失败清理。原生发布 UI 的自检调用真实 AppModel 和临时 ProfileStore，验证结果、取消、Quit 保护与活动会话标识保留，不启动 VPN。工作流截图导入结果窗口。实际保存对话框、用户选择/覆盖/取消及外部文件系统仍需真机检查；是否通过以 PR Actions 为准。
