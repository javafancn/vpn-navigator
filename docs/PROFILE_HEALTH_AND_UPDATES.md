# 配置健康、证书提醒与更新向导

0.6.0（Build 16）。配置详情右上角菜单 →「配置健康检查…」或「更新配置文件…」。沿用原生毛玻璃弹窗。

## 本地健康检查

检查当前自包含运行副本的引擎兼容性、所选路由模式及自定义规则；使用 macOS Security 解析内联 PEM CA／客户端 X.509 证书的有效期，显示尚未生效、已过期及 30 天内到期。每配置最多检查 64 项证书，全库自动检查最多 1000 个配置。损坏或不支持的材料明确显示未完成检查，不显示为健康。

不联系服务器、不上传配置、不请求私钥密码、不将身份导入钥匙串。PKCS#12 容器的有效期标为未检查。本地结果不验证完整信任链、吊销状态、私钥匹配或实际服务端证书，也不保证服务器可连接。多个 CA 的结果是材料清单提示，不代表所有列出的 CA 都会用于本次连接。实际连接继续由原有引擎执行 TLS 验证。

## 到期提醒

应用内结果始终可查看。系统证书通知单独选择开启，默认关闭；由用户操作请求通知权限，与连接状态通知开关独立。应用启动、重新激活、唤醒及运行期间每小时检查，导入和更新后刷新。关闭窗口而未退出应用仍可检查；退出应用后不承诺提醒。

每配置按证书指纹与 30／7／1 天及过期阶段去重，投递成功后持久化记录；换证后重新计算。应用停用期间错过的阶段不补发多条，只提醒当前阶段。通知标题和正文不包含配置名、服务器、证书主题或私钥；点击后打开相应配置检查。系统拒绝权限或专注模式可能不显示横幅，应用内结果仍保留。

## 配置更新

选中新的 `.ovpn`，在普通用户权限下读取并将邻接证书材料内联。预览只在内存持有新旧内容，不显示可能含私钥的全文差异。确认前不改配置或历史。预览展示健康问题及服务器／认证／身份材料是否改变，变化时要求明确确认；有健康提示时另行确认。相同内容不生成版本。

提交时必须断开 VPN、助手状态可核验且无需网络恢复；再次检查配置元数据及源／运行副本，拒绝过期预览。保留配置 UUID、名称、分组、收藏、备注、导入日期、路由模式、自定义规则和已有历史；来源文件名更新为本次文件名，旧源文件和运行副本另存历史。更新不自动连接。

服务器、协议、认证或内联身份材料改变时，保留配置 UUID，但轮换独立钥匙串标识；旧版配置缺少该字段时兼容使用配置 UUID。新版本不读取旧凭据，即使进程恰好在提交后退出也不会继承；普通用户输入草稿清空，旧凭据按旧标识尽力删除。只改注释或日志级别保留凭据关联。配置编辑与历史恢复也复用此事务和凭据隔离流程。备份恢复继续为新增配置创建全新凭据标识。

## 失败与中断

更新写前记录保存旧配置字节、旧元数据和本次历史 UUID，文件为 0600，所在目录为当前用户私有。归档历史、写入新源／运行副本和发布索引后，以原子写入「已提交」记录作为提交点。提交点前取消或失败恢复旧文件、元数据并移除本次新历史；提交后报告成功，记录清理由下一次读取重试。

重新打开配置库会先恢复未完成更新；损坏记录、索引冲突或不安全节点保留现场并拒绝猜测恢复。该机制针对进程中断；真正断电、磁盘故障、外置文件系统仍需实机验收。旧版本应用不理解更新记录，不能用于修复进行中的新版本事务。

## 自动化与人工边界

核心用例覆盖真实合成 X.509 日期、有效期边界、阶段去重、损坏材料、身份变化、保留元数据、外部材料迁移、过期确认、三个写入阶段故障、取消、重启恢复及符号链接拒绝。原生自检验证确认门槛、活动会话拒绝、凭据隔离、快速入口／智能连接排除和退出屏障；CI 截图健康检查与更新向导。

系统通知允许／拒绝／撤回、专注模式、真实钥匙串交互、Finder 对话框、睡眠与长时间运行仍需实际 Mac 验收。结果以当前提交的 Actions 为准，不替代既有发布门槛。
