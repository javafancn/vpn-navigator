# 规则 / 全局切换（0.3.7 / Build 10）

- **规则路由**：中国 IPv4 网段经原物理网关直连，其他默认 IPv4 流量经 VPN，保留局域网和 VPN 端点。
- **全局路由**：不安装中国直连规则，IPv4 默认路由经同一 VPN 隧道，保留局域网、VPN 端点及系统更具体路由的限制。
- **原始配置**：使用配置/服务器路由；与受管模式之间需先断开，因为连接建立时的 OpenVPN 路由参数不同。

连接中可在总览路由菜单、路由工作区、配置详情及菜单栏切换规则 / 全局；非活动配置的选择仅保存其下次连接偏好。规则模式需有至少 100 条已校验规则。实际模式来自助手 SessionReport，不用保存偏好冒充实际系统路由。显示切换进度，防止并发切换；可主动断开以取消，维护和退出等待事务完成。

两个受管模式统一使用 OpenVPN `--route-noexec`，由助手安装相同的端点 /32 和两个 /1 默认路由，并维护所有权日志。全局不依赖地区规则；规则模式额外安装经局域网/端点过滤的直连路由。切换只调整这些直连路由，事务本身不重启子进程、不重新认证，并保留管理会话与流量计数。PF 状态重置或物理网络变化仍可能触发现有安全断开/重连流程。成功后同步受保护重连上下文的模式，后续规则热更新亦更新路由版本。

XPC 要求匹配活动配置 UUID、连接 attempt UUID、当前模式及路由 revision UUID；检查与执行位于同一串行队列，防止旧请求和版本 ABA。输入/缺少规则在修改前拒绝。安装后核验端点、两个默认路由及代表性国内/境外查路结果；持续检查物理网关、直连网络和 IPv6/PF 边界。该查路验证不等于物理抓包或公网出口验证。

切换到全局先收紧 PF（如启用）并重置状态，再移除本应用拥有的直连路由；切换到规则先安装并查验路由，再放宽 PF。切换可能中断已有流量；启用实验性断线保护时会重置现有系统网络连接，包括其他 VPN，界面明确提示。IPv6 地区分流和物理网络零泄漏承诺不在本轮范围。

事务失败时先停止 OpenVPN，再按既有 DNS/路由/PF 恢复约束清理。未完成/归属不明日志继续保留，不强删系统其他路由。保存偏好在助手成功及新快照核验之后进行；保存失败仍显示实际已生效的模式，并提示下次连接前重新选择。快照无法核验时清除实际模式、保留恢复约束，不报告成功。

验证包括：核心双向计划/局域网和端点/规则与版本拒绝；四平台 helper debug 测试使用真实日志和 RouteExecutor、注入系统命令，检查 PF 排序、端点/default 保留、取消和含糊事务；原生 AppModel 使用临时 ProfileStore 和注入助手检查成功、拒绝、旧 revision、无规则、偏好写入失败与快照不可用。安装后的真实 XPC 在实际 Original TLS 会话中拒绝不支持的在线切换并检查会话未变。正式 helper 排除 debug 入口。

这些测试没有模拟成功的真实企业公网规则/全局流量切换。实际服务器、两向模式切换后的物理 IPv4/IPv6、DNS、并发网络变化、PF 边界及长时间流量仍按 QA 真机门槛验收；以 PR Actions 最终提交结果为准。

引擎选项依据：[OpenVPN 2.7 官方手册](https://openvpn.net/community-docs/community-articles/openvpn-2-7-manual.html)。
